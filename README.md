# SkyOps XP ✈️

Piattaforma di persistenza operativa, gestione economica e manutenzione avanzata per **X-Plane 12**.

Integrata con **SimBrief**, dotata di bacheca incarichi procedurali (Jobs), persistenza reale degli aeromobili (carburante, parcheggio, ore motore) e simulazione dell'usura con iniezione di guasti reali in X-Plane.

## Caratteristiche Principali
- **Flotta Persistente & Noleggio**: Tracciamento dell'aeroporto di stazionamento, carburante effettivo a bordo, ore cellula e motore.
- **Manutenzione Avanzata & Usura**: Usura progressiva di freni, pneumatici, olio, motore e cellula in base al tuo stile di volo (G-force al touchdown, overspeed, temperature).
- **Iniezione Guasti Reali (Failure Injection)**: Se la manutenzione viene trascurata, il sistema attiva le avarie native di X-Plane 12.
- **Job Board Procedurale**: Generazione di contratti di trasporto (VIP, Cargo, Charter) dall'aeroporto in cui ti trovi.
- **Integrazione SimBrief**: Importazione immediata dell'OFP tramite SimBrief Pilot ID / Username.
- **Dashboard Web Moderna**: Dark mode stile glass-cockpit, fruibile da PC, secondo schermo o tablet/iPad.
- **Zero Plugin Obbligatori**: Dialogo diretto e bidirezionale con X-Plane 12 tramite connettore nativo UDP / WebSockets.
